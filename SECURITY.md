# Politique de sécurité

## Signaler une faille

N'ouvrez pas d'issue publique pour une faille de sécurité : elle resterait visible de
tous le temps que la correction soit faite et déployée.

Deux voies privées :

- l'onglet **Security** du dépôt, bouton « Report a vulnerability »
- ou par courriel : annuaire.tsa@gmail.com

Décrivez ce que vous avez observé et comment le reproduire. Une capture ou une requête
suffit, inutile de rédiger un rapport.

## Ce qui est concerné

Le site annuaire-tsa.fr, son API et ce dépôt. En particulier tout ce qui toucherait aux
données des praticiens : accès non prévu à la base, fuite d'adresses électroniques,
contournement de l'administration.

Sont hors sujet : les rapports issus d'un simple scanner automatique sans démonstration,
les en-têtes manquants sans impact, et le contenu éditorial du site, qui relève de la
page « Vos données ».

## Ce à quoi vous pouvez vous attendre

Le projet est tenu par une seule personne, bénévolement. Les signalements sont lus et
traités manuellement, dans les meilleurs délais mais sans engagement de date. Il n'y a
ni programme de récompense, ni contrepartie financière.

Une faille qui exposerait des données personnelles est traitée en priorité sur tout le
reste.

## Merci

Signaler proprement plutôt que d'exploiter, c'est un service rendu aux familles qui
utilisent ce site. Vous serez crédité dans le README si vous le souhaitez.
